LOUVOR CONNECT ADVE — PUBLICAÇÃO NO GITHUB PAGES

Versão: demonstração pública PWA (aplicativo instalável no celular)

ARQUIVOS DO SITE:
  index.html
  manifest.webmanifest
  icon-192.png
  icon-512.png
  sw.js

COMO PUBLICAR:
1. Extraia (descompacte) o arquivo ZIP no seu computador.
2. Acesse: https://github.com/nogueiramateus16/louvor_connect_adve_publicacao
3. Clique em "uploading an existing file" se o repositório estiver vazio,
   ou em Add file > Upload files se já houver arquivos.
4. Selecione os CINCO arquivos do site acima e arraste para o GitHub.
   Não envie apenas o ZIP: o GitHub não descompacta automaticamente.
5. Clique em Commit changes (Salvar alterações).
6. Abra Settings > Pages e, em Build and deployment, selecione
   Deploy from a branch > main > /(root) > Save.
7. Após o GitHub indicar que a publicação foi concluída, abra:
   https://nogueiramateus16.github.io/louvor_connect_adve_publicacao/

INSTALAÇÃO NO CELULAR:
- Android/Chrome: menu ⋮ > Adicionar à tela inicial / Instalar app.
- iPhone/Safari: Compartilhar > Adicionar à Tela de Início.

IMPORTANTE — SEGURANÇA E LIMITAÇÕES:
Este site é um protótipo demonstrativo estático, SEM autenticação real,
SEM banco de dados e SEM sincronização entre integrantes.
Os registros de integrantes, músicas e escalas são guardados SOMENTE
no navegador usado (localStorage). Não são compartilhados entre aparelhos.
Utilize dados fictícios para testes. Não informe senhas ou dados pessoais
reais de integrantes nesta versão pública. A opção de convite real/individual
por WhatsApp ainda exige backend com autenticação e autorização seguras.
Faça backup JSON em Administração antes de limpar os dados do navegador.
